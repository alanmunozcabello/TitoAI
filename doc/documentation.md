## Architecture & Technical Design

### Technologies Used
- **Backend Framework:** FastAPI (Python 3.x)
- **Local LLM Server:** LM Studio running `Llama 3.1 8B Q4`
- **Frontend Stack:** HTML, CSS, JavaScript (Vanilla)

### High-Level System Flow
1. **User Input:** The user asks a question via the Web UI (`index.html`).
2. **Backend Processing:** The FastAPI application (`app.py`) receives the request.
3. **AI Generation:** The backend makes a request to the local LM Studio server via `routes_ai.py`.
4. **Response Delivery:** The response generated by the local Llama model is returned (either streamed or entirely) back to the UI.

## Developer Setup

### Prerequisites
- Python 3.10+
- [LM Studio](https://lmstudio.ai/) installed and running a compatible model on port 1234.

### Getting Started

1. **Start the LLM Server:**
   Open LM Studio, load your model (e.g., Llama 3.1), and navigate to the Local Server tab. Start the server ensuring it runs on `http://localhost:1234/v1`.

2. **Install Dependencies:**
   (Provide the command to install python packages, e.g., using a virtual environment)
   ```bash
   pip install fastapi uvicorn requests
   ```

3. **Run the Application:**
   Start the FastAPI development server:
   ```bash
   cd src
   uvicorn app:app --reload
   ```
   The application will be accessible at `http://127.0.0.1:8000`.

## API Reference

### `/api/chat` (Example Endpoint)
- **Method:** `POST`
- **Description:** Sends a message to the local AI assistant.
- **Request Body (JSON):**
  ```json
  {
    "message": "Hello TitoAI!"
  }
  ```
- **Response (JSON):**
  ```json
  {
    "reply": "Hello! How can I assist you today?"
  }
  ```
*(Note: Update the endpoint path and payload above to reflect exactly how `routes_ai.py` is configured.)*
